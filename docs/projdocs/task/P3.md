  - dependent-node cancellation after upstream failure
  - ordered lifecycle event publishing through an Evidence Bus boundary
- Added an in-memory Evidence Bus implementation for deterministic library tests.

## Configuration

P3 does not add new required configuration. Scheduler behavior is caller supplied:

```go
scheduler := orchestrator.Scheduler{
	Agents: map[agent.Role]agent.SubAgent{
		agent.RoleResearch: researchAgent,
	},
	Parallelism: 4,
	EvidenceBus: bus,
	EarlyStop: earlyStopFunc,
}
```

Per-node timeouts and retry attempts are carried on `agent.TaskNode`:

```go
node := agent.TaskNode{
	TaskID: "task_123",
	ID: "research",
	Role: agent.RoleResearch,
	MaxAttempts: 2,
}
```
