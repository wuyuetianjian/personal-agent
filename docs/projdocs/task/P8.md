## Configuration

P8 adds:

```yaml
coding_agents:
  default_backend: codex
  backends:
    codex:
      enabled: false
      adapter: codex
      binary: codex
      binary_env: PACHAT_CODEX_CLI_PATH
      timeout: 10m
      concurrency: 1
      execution_location: local
      inference_trust: public_remote
      privacy_policy: deny_confidential
      capabilities: [coding, code_review, code_test, code_debug]
      allow_direct_writes: false
```

Codex and Claude credentials remain owned by their CLIs. Personal Agent configuration only selects binaries, trust, timeout, concurrency, privacy policy, and capabilities.

## Known P8 Boundaries

- `pachat run` and local REST APIs do not yet dispatch coding task nodes to real Codex/Claude CLI processes.
- Runtime cost accounting for external coding agents is represented by result fields but not yet persisted into the P5 cost package.
- Cross-review orchestration is supported by adapter and registry boundaries but is not yet wired into Leader/Scheduler planning.
- Real Codex/Claude opt-in E2E tests are not added yet; current coverage uses mock binaries and local Git fixtures.
- Permission confirmation for push/deploy/sudo/destructive commands remains a follow-up Runtime integration task.

## Next Step

Wire `internal/codingagent.Runner` into Runtime/Scheduler as a `coding` Sub-Agent backend, then add opt-in real Codex/Claude E2E coverage after the mock integration path is stable.
