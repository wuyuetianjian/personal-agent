## Status

This archive does not mark every P13 product item complete. It records the local observability and secret-leak regression slice so the next agent can continue the remaining P13 release-gate work from `docs/projdocs/P0_P14_EXECUTION_PLAN.md`.

## Boundaries / Unfinished P13 Items

- P13-01 Structured Logging is only a library foundation. Runtime/CLI/API call sites are not yet fully instrumented with structured log records.
- P13-02 Metrics is a local JSON metrics foundation. It does not yet expose every planned metric such as token usage, cost, RAG latency, browser actions, coding-agent runtime, MCP calls, trigger fires, notifications, or detailed error categories.
- P13-03 OpenTelemetry tracing is not implemented.
- P13-05 Global resource governor is not implemented.
- P13-06 Disk pressure monitoring and cleanup/governance are not implemented.
- P13-07 Graceful shutdown only uses the existing HTTP shutdown path. Workflow checkpoint flushing, browser-session close ordering, coding-agent process termination, event flushing, and DB close ordering still need full implementation.
- P13-08 Crash/chaos tests are not implemented.
- P13-09 Race/concurrency hardening under `go test -race ./...` has not been completed.
- P13-10 Load tests are not implemented.
- P13-11 Prompt-injection defense suite is not implemented.
- P13-12 Secret-leak defense suite has only observability/API-focused regression coverage. Prompts, notifications, exports, UI evidence previews, and all tool-result channels remain follow-up work.
- P13-13 Shell/command injection hardening is not complete.
- P13-14 Path traversal/filesystem scope hardening is not complete.
- P13-15 SSRF/network egress policy is not complete.
- P13-16 API security hardening remains incomplete for auth, CORS, CSRF, request body limits, rate limiting, full error sanitization, and security headers.
- P13-17 External agent sandbox hardening is not complete.
- P13-18 Browser security regression suite is not implemented.
- P13-19 Durable security audit log is not implemented.
- P13-20 Dependency/vulnerability CI is not implemented.
- P13-21 Eval golden suite is not implemented.
- P13-22 Measurable quality gates are not implemented.
