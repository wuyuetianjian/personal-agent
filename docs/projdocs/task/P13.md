# P13 Reliability / Security / Observability Release Gate Completed

## Status

P13 reliability/security/observability release-gate foundations completed locally on 2026-09-06.

## Completed

- Added `docs/p13_reliability_security_observability.md` as the scoped P13 requirements and acceptance document.
- Added `internal/observability` with:
  - centralized secret-like value redaction
  - structured JSON log records with P13 fields
  - in-process counters and gauges
  - runtime metric snapshots backed by SQLite task/workflow counts
  - health and readiness report types
- Reused the observability redactor for API-facing text sanitization.
- Updated `pachat serve` health/readiness behavior:
  - `/healthz` returns JSON process liveness
  - `/readyz` returns JSON database, migration, Runtime, and dependency checks
  - dependency warnings are reported separately without making the process unready
- Added `GET /metrics` to `pachat serve` with JSON counters, gauges, task count, workflow count, active agent count, and queue depth.
- Added HTTP request/error/activity metrics middleware around the local API handler.
- Added secret-leak regression coverage for:
  - structured log messages and fields
  - metric names
  - readiness dependency remediation
  - serve health/readiness/metrics response shapes
- Added local tracing spans with redacted names, IDs, attributes, and errors.
- Added P13 security/reliability configuration:
  - `security.api.*`
  - `security.network.*`
  - `reliability.resources.*`
  - `reliability.disk.*`
- Added API security middleware for bearer auth, CORS, request body caps, per-client rate limiting, sanitized error codes, and browser security headers.
- Added a global in-process resource governor for workflow/model/browser/coding-agent/MCP/open-file/temp-disk limits and wired workflow acquisition into Runtime.
- Added disk pressure checks and surfaced disk pressure in serve readiness dependencies.
- Added graceful shutdown coordination primitives.
- Added command injection, path traversal, and SSRF/network egress policy helpers with adversarial tests.
- Added prompt-injection fixtures and untrusted-source classification.
- Added external coding-agent sandbox policy checks for isolated worktrees, direct writes, and minimal environment.
- Added browser security regression helpers for cross-domain navigation, unsafe downloads, credential pages, OAuth, and prompt injection.
- Added durable security audit persistence:
  - `internal/storage/migrations/0004_p13_audit.sql`
  - `internal/audit`
- Added golden eval cases and measurable quality-gate threshold evaluation.
- Updated English and Chinese README sections.

P13 now provides local policy boundaries, persistence, and regression gates for the release criteria. It does not claim production-grade OS-level sandboxing, distributed tracing export, external vulnerability services, or kernel/browser isolation.
