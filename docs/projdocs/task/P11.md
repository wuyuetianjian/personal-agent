# P11 Runtime Integration Closure Slice Completed

## Status

P11 first runtime workflow dispatch slice completed locally on 2026-09-06.

This archive does not mark the full P11 release gate complete. It records the first closure slice so the next agent can continue P11 from the remaining gates in `docs/projdocs/P0_P14_EXECUTION_PLAN.md`.

## Completed

- Added `docs/p11_runtime_integration_closure.md` as the scoped P11 requirements and acceptance document.
- Extended `internal/runtime.Runtime` so the composition root owns:
  - workflow store
  - project store
  - workflow engine
- Added a Runtime-owned workflow engine that:
  - loads persisted workflow runs
  - recovers non-terminal workflow nodes
  - skips completed checkpointed nodes during recovery
  - checks registered capability existence and enablement before dispatch
  - enforces project capability allowlists before dispatch
  - preflights node budget limits from workflow input JSON
  - dispatches local read-only nodes through the existing orchestrator scheduler
  - persists per-node checkpoints with evidence IDs and usage JSON
  - marks workflows completed, failed, or cancelled
- Added local workflow Sub-Agent adapters for:
  - `memory.search`
  - `rag.search`
  - `verification.verify`
- Added runtime tests for:
  - workflow execution and checkpoint persistence
  - recovery skipping completed nodes
  - project policy denial for disallowed capabilities
- Updated English and Chinese README sections.

## Boundaries / Next Steps

- P11 is not fully complete. This archive covers the first persistent workflow dispatch slice, not P11-01 through P11-25 in full.
- `Runtime.Run()` still has the existing direct local memory/RAG/verification fast path; later P11 work should move full task execution onto planned scheduler nodes.
- Workflow dependencies are not yet persisted in `workflow_nodes`; this slice dispatches recoverable stored nodes as independent scheduler nodes.
- The executable workflow capability set is intentionally limited to local read-only capabilities: `memory.search`, `rag.search`, and `verification.verify`.
- BrowserAgent, CodingAgent, MCP tool execution, model-backed Leader planning, public model escalation, live provider usage metering, and Runtime-backed multi-turn chat remain follow-up P11 gates.
