# P1 Completed: Model And Privacy Foundation

## Status

Completed locally on 2026-09-05.

## Completed Capabilities

- Added model trust levels:
  - `local_private`
  - `local_sandboxed`
  - `trusted_remote`
  - `public_remote`
- Added model capabilities, provider metadata, model metadata, pricing, and registry validation.
- Added independent model policy selection for Leader and Sub-Agent roles.
- Added mockable provider interfaces for chat, embeddings, and reranking.
- Added an OpenAI-compatible provider boundary with injectable HTTP transport.
- Added a Privacy Gateway with:
  - HMAC-SHA256 pseudonymization
  - sensitive credential redaction
  - credential dump blocking
  - audit metadata
- Enforced fail-closed Privacy Gateway usage for public remote model calls.

## Configuration

The example configuration includes independent local-private model settings for the Leader, research Sub-Agent, and verification Sub-Agent roles:

```yaml
agent:
  leader:
    model: local-planner
    trust_max: local_private
  subagents:
    research:
      model: local-planner
      trust_max: local_private
    verification:
      model: local-planner
      trust_max: local_private
```

Model providers and models remain configured through `configs/config.example.yaml`; no provider URL, credential, or secret is hardcoded in the implementation.
