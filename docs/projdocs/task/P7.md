# P7 Completed: Runtime Integration / Personal Agent MVP

## Status

P7 Runtime MVP completed locally on 2026-09-06.

## Completed Capabilities

- Added `internal/runtime` with:
  - local-first route types and unified runtime result types
  - runtime builder using configured storage and existing migrations
  - local BM25 RAG pipeline with context compression
  - memory search over semantic project facts and recent episodic events
  - SQLite-backed evidence persistence using the existing `evidence` table
  - final local synthesis with verification report
  - zero public model calls for local-only evidence paths
- Extended agent roles with:
  - `retrieval`
  - `memory`
  - `reasoning`
  - `tool`
  - `synthesis`
- Extended task persistence with:
  - completed runtime result updates
  - failed runtime state updates
- Updated `pachat run` so normal task execution now enters Runtime and no longer returns `No-op task completed.`
- Updated `POST /tasks` so configured API servers can execute the same Runtime path for non-long tasks.

## API Surface

Added:

```text
api.NewServerWithRunner(...)
```

This keeps the existing P6 handler constructor usable for state-only long-task tests while allowing P7 callers to inject a Runtime runner.

## Configuration

P7 MVP does not add new hardcoded environment values. Runtime construction uses the existing config and SQLite storage settings. Public model escalation remains disabled in this MVP slice, so remote token usage is expected to be zero.

P7 MVP tests cover local-only RAG execution, zero public model usage, runtime evidence IDs, task completion persistence, API runtime execution, and CLI output shape without the no-op answer.
