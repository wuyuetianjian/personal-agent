# P2 Completed: RAG And Memory

## Status

Completed locally on 2026-09-05.

## Completed Capabilities

- Added `internal/rag` with:
  - document and chunk models
  - deterministic chunking
  - content hashes
  - SQLite document/chunk persistence
  - local BM25 retrieval
  - Reciprocal Rank Fusion

- Extended `internal/memory` with:
  - working memory store and expiration cleanup
  - existing episodic memory store retained for CLI compatibility
  - semantic memory store
  - optional semantic memory indexing hook into RAG

## Configuration

P2 does not add new required configuration. Qdrant connection values are caller-supplied to `rag.QdrantClient`:

```go
client := rag.QdrantClient{
	BaseURL:    baseURL,
	Collection: collection,
	APIKey:     apiKey,
	HTTPClient: httpClient,
}
```

Tests read optional Qdrant integration values from:

```sh
QDRANT_URL
QDRANT_COLLECTION
QDRANT_API_KEY
```

The integration test skips cleanly when Qdrant is not configured or unavailable.

P2 tests cover BM25 ranking, deterministic RRF ordering, Qdrant integration skipping, working memory lifecycle, semantic memory indexing, episodic memory compatibility, and context compression evidence preservation.

## Known P2 Boundaries

- The CLI still does not run RAG during task execution.
- Qdrant is a boundary wrapper only; there is no configured production vector index pipeline yet.
- Reranking is an interface boundary only; no model-backed reranker is wired yet.
- Evidence is preserved in RAG results and compressed context, but global Evidence Bus integration is planned for P3-P5.
- No Sub-Agent scheduler or orchestration DAG is implemented yet.
