How to use:

- Configure the Leader model under `agent.leader.model_id`.
- Keep `agent.planner.enabled: true` and set `agent.planner.max_nodes` in the mountable config file.
- Ensure the selected model has `chat` and `json_schema` capabilities in `models.registry`.
- Configure optional `agent.subagents.reasoning` and `agent.subagents.synthesis` settings to tune local model temperature and output token limits.

Runtime data locations:

- Planner state is not persisted separately.
- Planned nodes are persisted through the existing workflow tables and checkpoints.
- Model reasoning summaries are stored as model evidence.
- Model synthesis answers are stored in workflow checkpoints and persisted to the task final answer.
