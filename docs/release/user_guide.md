# User Guide

## English

Use `pachat chat` for interactive local memory, `pachat run` for one task, `pachat task` and `pachat workflow` for long-running work, `pachat knowledge` for local files, `pachat project` for policy contexts, `pachat approval` for pending permission decisions, `pachat trigger` and `pachat watcher` for proactive work, and `pachat notification` for local inbox messages.

Browser, Coding Agent, MCP, and public model paths are governed. They return denied or unavailable results unless enabled through configuration and permissions.

## 中文

使用 `pachat chat` 进行带本地记忆的交互会话，使用 `pachat run` 运行单次任务，使用 `pachat task` 与 `pachat workflow` 管理长任务，使用 `pachat knowledge` 管理本地知识，使用 `pachat project` 管理策略上下文，使用 `pachat approval` 处理权限审批，使用 `pachat trigger` 与 `pachat watcher` 配置主动任务，使用 `pachat notification` 查看本地通知。

Browser、Coding Agent、MCP 与 public model 路径都受治理控制。未通过配置和权限显式启用时，它们会返回 denied 或 unavailable。
